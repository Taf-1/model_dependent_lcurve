# LCURVE python wrapper for model dependent params
======================================================

Python tool used to wrap around the 'new' lcurve, managed by AJ Brown et al. This code simply takes in lightcurve files, model files and config files to generate a model over the data with a MCMC run to estimate binary parameters that are model dependent.

This codes main use is for ULTRACAM data, where targets lack spectra and need estimates for a survey paper or for potential ESO proposals.
